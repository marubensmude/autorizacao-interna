1Proprietário (Outorgante)

Dados de quem autoriza a venda. Estes dados aparecem na autorização que o cliente vai conferir e aceitar.

2Imóveis

Dados mínimos para identificar e precificar cada imóvel autorizado. Para o mesmo proprietário, você pode adicionar quantos imóveis quiser; será gerada uma única autorização com um só aceite.

3Condições comerciais

Parâmetros da intermediação. Padrão Mude já preenchido; ajuste se necessário.

4Gerar link de aceite

O link leva o cliente direto para a autorização preenchida. Ele só confere e aceita; o documento volta para o seu e-mail com o registro de IP.
Você alterou dados depois de gerar o link. O link anterior não tem essas correções: toque em Gerar link corrigido para criar o novo e envie esse ao cliente.
